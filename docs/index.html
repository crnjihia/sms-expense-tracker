01 / Getting started

Choose how to run it

Use an Android phone with the app, or build and launch it yourself from the source code.

A

Run on an Android phone

  1. Install a build of the app on a device running Android 8.0 (API 26) or newer.
  2. Open the app. Grant SMS access if you want it to read existing messages and capture new ones automatically.
  3. Allow notifications if you want to receive budget alerts.
  4. Prefer not to grant SMS access? Choose Manual Import and paste messages yourself.

Permissions are optional for manual use. Without SMS access, automated capture and inbox sync are unavailable, but manual import and the rest of the app remain usable.

B

Build and run from source

Requires Android Studio, JDK 17, and Android SDK 34. Clone the repository, then open it in Android Studio and run the app configuration on a device or emulator.

Windows PowerShell
git clone https://github.com/crnjihia/sms-expense-tracker.git
cd sms-expense-tracker
.\gradlew.bat assembleDebug
.\gradlew.bat installDebug
macOS / Linux
git clone https://github.com/crnjihia/sms-expense-tracker.git
cd sms-expense-tracker
./gradlew assembleDebug
./gradlew installDebug

The debug APK is written to app/build/outputs/apk/debug/app-debug.apk. Installation requires a connected Android device or running emulator.

02 / Using the app

Your everyday guide

Start with a transaction source, then explore the dashboard, budgets, and reports.

01 — Add transactions

Sync messages or import manually

With SMS permission, incoming supported messages are processed on-device. Use the home screen’s inbox sync action to backfill eligible messages already in your inbox.

For manual import, open the ＋ button on Home. Put one message on each line in this format:

MPESA|QA12BC34DE Confirmed. Ksh1,500.00 sent to JANE DOE 0712345678 on 15/08/2024 at 2:30 PM. New M-PESA balance is Ksh5,230.00. Transaction cost, Ksh15.00.

Tap Import to see how many messages were added and how many could not be parsed. Only supported message formats are recognized; importing the same transaction again will not add a duplicate.

Examples are synthetic. Find more in sample_messages.txt and sample_messages.csv. The manual screen expects sender|body lines, not raw CSV rows.

02 — Set a plan

Create monthly budgets

Open Budgets, tap ＋, choose a category and month, and enter a limit in Kenyan Shillings. The budget screen shows spending progress against each limit.

Alerts can be checked from the budget or home screen. Background checks run periodically, and notifications depend on notification permission and device settings.

03 — Find patterns

Explore your reports

Open Reports to review spending over the available periods, see category breakdowns, and compare monthly totals. Transactions that have not been categorized may not appear in category totals.

Use Transactions to browse, search, or filter the underlying records.

04 — Make it yours

Adjust settings and export

In Settings, choose the theme and currency display, configure automation and budget alert preferences, and optionally enable a biometric or device-credential app lock.

Choose Export All Transactions (CSV) to save a CSV file using Android’s document picker. The export can contain sensitive financial details; store and share it carefully.

Wipe All Data permanently removes local transactions, budgets, rules, and SMS sync pointers. Review the confirmation before proceeding.

✓

Private by design

Your financial data stays on your phone

The app has no Internet permission. Message parsing, categorization, and transaction storage happen locally. SMS permissions let Android deliver or provide SMS data to the app; they do not grant permission to send SMS messages.

CSV files you export are outside the app’s private database and should be handled with care. App lock is optional and is separate from database encryption.
